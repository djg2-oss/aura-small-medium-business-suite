# Aura Small-Medium Business Suite

Unified website/app foundation for smaller to medium businesses, websites, and apps.

## Purpose
Fast launch, conversion-focused, performance-first sites that stay light on the user’s computer under AuraXur OS simulation functions. Hybrid local + host as needed.

## Features
- Clean, modern Tailwind UI
- Template categories ready for Codeless Builder (Music, Service, Portfolio, Coaching, Landing, Education…)
- File/folder structure awareness for future deploys
- Multi-simulation shared memory notes for latency reduction
- Direct growth path to Medium-Large Suite and full G2PTECHOFFICE / AuraG2P Music Studio Platform

## Quick Start
Open `index.html` or serve statically:
```bash
python -m http.server 8080
```
